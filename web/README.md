# Solomon Islands Data Map: website

The static dashboard published at **https://thomasmartin.id.au/SolomonIslandsDataMap/**.
It replaces the Dash app (still in `SolomonIslandsDataMap/`) so the site can be hosted on GitHub Pages
with no Python server.

Stack: Astro + React islands, Tailwind v4, shadcn/ui (Base UI, `base-lyra` style), MapLibre GL, Recharts
(shadcn charts) and TanStack Table. The theme, header and footer are copied from the personal site
(`Gippers/gippers.github.io`) so the dashboard reads as part of thomasmartin.id.au. The one difference is the accent colour: mint
(Bootswatch Minty, as in the Dash app) instead of violet, set at the end of `src/styles/global.css`.

## Pages

| Route          | Dash page              |
| -------------- | ---------------------- |
| `/`            | Census Map             |
| `/election/`   | Election Map           |
| `/population/` | Population Projections |
| `/table/`      | Data Table             |

Filters are kept in the URL query string, so a view can be shared and the selection carries between pages.

## Data

Everything the site needs is in `public/data/`, generated by the Python package and committed:

```bash
# from the repo root
python -m SolomonIslandsDataMap.export_static         # from testData/
python -m SolomonIslandsDataMap.export_static --aws   # from the pickle in S3
```

The export lives in `nbs/08_export_static.ipynb` and reuses the `SolomonGeo` getters, so the numbers match
the Dash app. `src/lib/data.ts` holds the small TypeScript versions of the Dash callbacks (`get_census`, `get_pop`, ...).

## Development

```bash
cd web
npm ci
npm run dev        # http://localhost:4321/SolomonIslandsDataMap/
npm run build      # static site in dist/
npm run typecheck
```

## Adding shadcn components

`npx shadcn add <component>` works as normal when `ui.shadcn.com` is reachable.

## Deploying

`.github/workflows/deploy.yaml` builds this site plus the nbdev docs (served at `/docs/`) and publishes
both to GitHub Pages on every push to `main`. In the repo settings, Pages → Source must be **GitHub Actions**.
Because the user site `gippers.github.io` has the custom domain `thomasmartin.id.au`, this project site is
served at `thomasmartin.id.au/SolomonIslandsDataMap/` automatically.
